Página do restaurante/prova 2026B

Sobre o projeto
Este projeto é uma pagina de um restaurante para a prova de desenvolvimento de aplicações.

Tecnologias utilizadas

* HTML
* CSS
* JavaScript

Como executar

1. Baixe ou clone o repositório.
2. Abra a pasta do projeto no Visual Studio Code.
3. Abra o arquivo `index.html` utilizando o Live Server.
4. A página será aberta no navegador.

Estrutura do projeto

* `inicio.html` — estrutura da página.
* `style.css` — estilos da página.
* `cadastro.js` — comportamentos e interações.
* `.gitignore` — arquivos e pastas que não devem ser versionados.
